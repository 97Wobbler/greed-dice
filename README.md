# Greed Dice 점수판

실제 주사위 게임과 함께 사용하는 모바일 우선 점수 기록 도구입니다. 게임 규칙을 판정하지 않고, 현재 점수와 플레이어별 누적 점수를 빠르게 관리합니다.

## 기능

- 현재 점수를 50점·500점 단위로 조정하거나 직접 입력
- 현재 점수를 원하는 플레이어의 누적 점수에 더하기
- 점수 지급 뒤에도 현재 점수와 진행 순서 유지
- 플레이어 이름과 진행 순서 설정
- 마지막 점수 변경 되돌리기
- 브라우저에 진행 상황 자동 저장
- 확인 후 모든 점수 초기화

## 로컬 실행

```bash
npm install
npm run dev
```

## 배포

`main` 브랜치에 변경 사항이 올라가면 GitHub Actions가 GitHub Pages에 정적 사이트를 배포합니다.
